# Auth-Desk

**Вход и регистрация на мятой бумаге.**

Стол из скомканного листа, блокнот с закладками, жёлтый стикер с тестовыми данными.
Войдёшь — на листе встанет штамп «Принято», лист сомнётся в комок и улетит,
а на весь экран от руки напишется «Вы вошли».

## Возможности

- **Вход и регистрация** на одном листе. При переключении старый лист выдёргивают из-под скотча,
  сминают и бросают со стола, а под ним уже лежит новый.
- **Анимация входа**: рука со штемпелем прилетает из угла экрана, ставит «Принято» и уходит;
  затем лист комкается и улетает.
- **Живой стол**: комки, обрывки записок и штемпельную подушку можно таскать мышкой. Предметы
  не двигаются сами, не заезжают под блокнот и не выходят за край экрана.
- **Мелочи**: курсор — рука (вытянутый палец, щепоть при зажатой кнопке, рука с ручкой над полем ввода);
  если 20 секунд ничего не делать, на полях медленно рисуются каракули; щелчок по штемпельной подушке
  пачкает палец, и следующие щелчки оставляют всё бледнее отпечатки (Esc вытирает палец).
- **Без внешних зависимостей**: ни npm-пакетов, ни Google Fonts, ни CDN. Шрифты и картинки лежат
  в репозитории, страница работает без интернета.
- **Нормальная защита входа**: scrypt, сессии без хранения токена, ограничение перебора, защита от CSRF
  (подробнее — [ниже](#безопасность)).

## Быстрый старт

Нужен **Node.js 22.13 или новее** (используется встроенный модуль `node:sqlite`).

```bash
git clone https://github.com/chebupeka/Auth-Desk.git
cd Auth-Desk
npm start
```

Откройте http://localhost:3000.

Для разработки с автоперезапуском сервера:

```bash
npm run dev
```

### Настройки

| переменная | по умолчанию       | что делает                      |
|------------|--------------------|---------------------------------|
| `PORT`     | `3000`             | порт HTTP-сервера               |
| `HOST`     | `127.0.0.1`        | адрес, на котором слушает сервер |
| `DB_PATH`  | `data/app.db`      | путь к файлу базы SQLite        |

## Тестовые данные

При старте сервер создаёт локальную базу `data/app.db` и добавляет пользователей, если их ещё нет:

| логин | пароль   |
|-------|----------|
| test  | test     |
| anna  | anna2026 |
| ivan  | ivan2026 |

Кнопка «подставить» на жёлтом стикере вписывает `test / test` в форму.

Пересоздать базу с нуля (сервер перед этим остановить):

```bash
npm run db:reset
```

## API

| метод | путь            | тело                  | ответ                                        |
|-------|-----------------|-----------------------|----------------------------------------------|
| POST  | `/api/login`    | `{ login, password }` | `200 { user }` + cookie `sid`, `401`, `429`  |
| POST  | `/api/register` | `{ login, password }` | `201 { user }` + cookie `sid`, `400`, `409`  |
| POST  | `/api/logout`   | `{}`                  | `200 { ok: true }`                           |
| GET   | `/api/me`       | —                     | `200 { user }` или `200 { user: null }`      |

Ошибки приходят как `{ error, field? }`, где `field` — поле формы, к которому относится ошибка.

Пример:

```bash
curl -i -X POST http://localhost:3000/api/login \
  -H "Content-Type: application/json" \
  -d '{"login":"test","password":"test"}'
```

**Правила регистрации:** логин — 3–32 символа (буквы любого алфавита, цифры, `_ . -`), регистр не важен
(«Anna» и «anna» — один человек); пароль — от 4 до 128 символов.

## Безопасность

- **Пароли** хранятся как `scrypt` с индивидуальной солью, сравнение — через `timingSafeEqual`.
- **Сессии**: в cookie лежит случайный токен, в базе — только его sha256. Утечка базы не даёт готовых сессий.
  Срок жизни — 7 дней, просроченные удаляются по таймеру.
- **Перебор паролей**: после 5 неверных попыток подряд пара «IP + логин» блокируется на минуту (`429` и `Retry-After`).
  Попытка бронируется до проверки пароля, поэтому пачка параллельных запросов не обходит лимит.
- **Нет утечки логинов по времени**: для несуществующего логина всё равно считается scrypt,
  а ответ одинаков — «Неверный логин или пароль».
- **CSRF**: все POST-запросы принимаются только с `Content-Type: application/json`, а обычная HTML-форма
  с чужого сайта так отправить не может.
- **Статика**: защита от выхода за пределы `public/` и набор защитных заголовков.

## Как устроено

```
server.js            точка входа: база, тестовые пользователи, HTTP-сервер
src/
  app.js             маршруты API и раздача public/
  auth.js            хеширование паролей, вход, регистрация, сессии
  db.js              схема SQLite: users и sessions
  http.js            хелперы: JSON, cookie, заголовки, HttpError
  throttle.js        ограничение неудачных попыток входа
  seed.js            тестовые пользователи
public/
  index.html         страница
  app.js             форма, переключение «вход / регистрация», анимация входа
  desk.js            предметы на столе и их перетаскивание
  cursor.js          курсор-рука вместо системной стрелки
  doodles.js         каракули на полях, если 20 секунд ничего не делать
  prints.js          отпечатки пальцев в краске со штемпельной подушки
  style.css          оформление
  assets/            бумага, комки, скотч, стикер, маски штампа, кадры руки
  fonts/             Caveat, Oswald, PT Mono (кириллица и латиница)
scripts/
  reset-db.js        пересоздание базы
  prepare-hand-assets.py  сборка кадров руки из исходников
test/api.test.js     тесты API и троттлинга
img/                 исходные картинки для ассетов
```

Подробнее о страницах:

- `public/app.js` — при обновлении страницы всё начинается заново: прошлая сессия закрывается,
  открывается пустая форма входа. Высота листа в режимах «вход» и «регистрация» одинаковая.
- `public/desk.js` — комки упираются друг в друга, не расталкивая соседей; отпущенный предмет остаётся там,
  где его положили.
- `public/assets/hand/` — кадры руки со штампом. Объём даёт масштаб руки (высота над листом) и тень по её
  силуэту. Если кадров нет, вместо руки штамп просто «падает» на лист.

## Ассеты

Картинки в `public/assets/` сделаны из исходников в `img/`: фон вырезан, текстуры листов переведены
в серые карты складок (они ложатся на цвет бумаги через `multiply`), всё сжато в WebP.

### Кадры руки со штампом

Исходники — `img/hand-stamp-*.png`, `img/stamp-imprint-frame.png`, `img/stamp-on-desk.png`, `img/ink-pad.png`
(промпты, по которым они сделаны, лежат в `img/*-prompts.json`).
Если перегенерировали картинки, пересоберите ассеты (нужны Python 3, Pillow и numpy):

```bash
python scripts/prepare-hand-assets.py
```

Скрипт вырезает серый фон, обрезает все кадры руки по общей рамке (иначе рука дёргается при смене кадра)
и записывает в `public/assets/hand/hand.json`, где в кадре центр основания штампа и какую часть ширины
оно занимает. Для нынешних картинок это 0.351, 0.349 и 0.441 исходного кадра — если у новых другая
композиция, передайте свои значения через `--anchor` и `--base`. Однотонные картинки скрипт пропускает.
